# Detached Chat

Agent Skill that reopens past Claude Code and Codex chats by name, each in its own new Windows Terminal window, and hands work to a Claude Code window chat or background chat that keeps running after the session that started it closes. Everything but background chats needs Windows Terminal.

- `SKILL.md`: the procedure the agent follows
- `references/codex.md`: what differs when the chat to reopen is a Codex one
- `AGENTS.md`: rules for editing this skill
